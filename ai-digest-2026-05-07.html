【Anthropic Dreaming】 ↔ 在手项目:Macaron

他们在做什么:Anthropic 5/6 发布 Dreaming——一个在 agent 会话之间运行的后台进程,自动复盘过去会话、识别模式、把信号沉淀进 memory store,让 agent 跨会话变得越来越聪明。研究预览阶段。

对我们的启示:好消息——技术路径被头部公司公开背书。坏消息——Anthropic 已经把 agent memory 做成基础设施层。Macaron 必须把价值锁在「个人化场景 + 中文社交 + 私域记忆」,而不是通用记忆引擎本身。

🚀 新兴方向

Outcomes-Based Agent Execution — 目标驱动的 agent 范式 🔴 强信号

今日信号:Anthropic Outcomes 升到 public beta——你写一个 rubric,Claude 单独起一个 instance 当 grader,在独立 context 里评 agent 输出,失败就反馈具体哪里不对,agent 重做。Anthropic 内测:在标准 prompt loop 上提升 10 个点的成功率;docx 提升 8.4%、pptx 提升 10.1%。

为什么现在:过去 3 年 prompt engineering 是核心技能,但 prompt 描述「怎么做」、不是「做成什么样」。Outcomes 这种 rubric + grader + 迭代的范式,把 agent 输出从"看起来对"提升到"按客观标准对"——这是 agent 真正进入企业 SLA 场景的前提。

投资逻辑:赌「目标驱动的 AI 工作流」会替代「prompt 驱动的 AI 工作流」。可投方向:rubric 模板市场、垂直行业 grader 模型、agent 输出审计工具、按交付质量收费的 outcome-based BPO。

Agent Self-Improvement via Memory Consolidation — 记忆萃取式自我进化 🔴 强信号

今日信号:Anthropic Dreaming 让 agent 在「下班时间」自动复盘过去会话、抽取模式、curate 记忆——agent 第一次官方原生地"跨会话变聪明"。原文:"Dreaming reviews your agent's past sessions, extracts patterns, and curates memories so your agents learn over time."

投资逻辑:赌「agent 学习曲线」成为新护城河——一个用了 6 个月的 agent 会比一个新 agent 显著更好用,这是 SaaS 时代「越用越值钱」效应在 AI 时代的复刻。可投方向:个人 AI memory 引擎、企业 memory 治理工具、跨 agent memory 同步平台、memory 隐私层。

小白深度解读

背景:过去 2 年 AI agent 有两个核心痛点——1)它经常不知道"做完了没有",有时候返回一坨看起来对、其实不对的东西;2)它跨会话不记得,昨天教过的它今天忘了。这两件事让企业不敢把 agent 用在重要场景。

事件:Anthropic 一次性把这两件事都做了——Outcomes 解决「做到什么程度算完」,Dreaming 解决「跨会话学习」。两个发布同一天,产品逻辑是配套的:Outcomes 让 agent 在单次任务里达标,Dreaming 让 agent 跨任务进化。

把这两件事拼起来读——agent 范式从「prompt 工程」(描述步骤)切到了「outcome 工程」(描述结果)+「memory 工程」(沉淀经验)。这是 AI 应用栈的一次根本性架构转移,影响所有在做 AI 产品的团队。如果今年不开始想「我的 agent 怎么定义 outcome、怎么沉淀 memory」,12 个月后会被这个 paradigm 卷死。

意义:对 portfolio 全体的实操建议——立刻开会评估两件事:1) 我们产品里 agent 输出的"成功标准"能不能写成一个 rubric?如果可以,Outcomes 这套范式可以直接接。2) 我们用户的"个人化记忆"能不能做成 Dreaming 风格的"周期性 memory curation"?Macaron 是直接对标的方向,其他项目可以借这个 thesis 来重新设计 retention 体验。

事件:这一期 50 分钟 Boris 把 Anthropic 内部的工作流"打开给外界看"。最让人震撼的一段是——Boris 说他白天有几百个 agent 在跑、晚上有数千个,通过 slash loop(让 Claude 用 cron 给自己定时调度)做"无人值守"工作。他还有几十个常驻 loop:babysit PR、修 CI、每 30 分钟从 Twitter 抓反馈分类。

Boris 的 SaaSpocalypse 框架是这一期最值钱的部分——他借 Hamilton Helmer 的 7 Powers 拆开来分析:switching cost(用户迁移成本)和 process power(流程沉淀)这两个传统 SaaS mote 因为 AI 变弱,但 network effects(网络效应)、scale economies(规模经济)、cornered resources(垄断资源)反而被 AI 强化。这个判断对 portfolio 13 家直接转译为:如果你的护城河是"用户切换成本高"或"流程跑得熟",12 个月内会被冲掉;如果你的护城河是"用户多到自循环"、"规模带来的成本优势"、"独占的数据/牌照/物理资产",反而是被 AI 强化的赢家。
